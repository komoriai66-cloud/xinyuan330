# 反馈工作台 UI 验收 · 2026-09-30

使用 `npm run preview` 的内存 SQLite 和假凭证测试，没有写入生产数据库。

## 视觉与空间

- 管理页沿用当前页面的黑白色、细边线、按钮圆角、15px 正文与 22px 详情标题；新增操作放入紧凑的折叠区和消息菜单。
- EPhone、UWU 各自沿用原信箱样式。新增辅助操作、搜索、处理结果和凭证入口低于主内容的视觉权重。
- 保留原管理消息气泡的移动端最大宽度和回复框尺寸。给长标题增加宽度约束，不修改标题字号。
- 检查 320、375、390px 的长中文、连续英文和数字标题、昵称、正文、回复区、待办表单、消息菜单及确认弹窗。
- 两站列表和详情、管理列表和详情均没有横向溢出；页面实际宽度与测试宽度一致。
- 管理详情标题三种宽度均为单行 33px 高；UWU 信件标题三种宽度均为单行 17.6px 高。
- 管理页“处理 / 待办 / 备注与环境”在 320px 下保持单行。320px 通知弹窗宽 288px，左右各留 16px。
- 修复窄屏详情隐藏列表区后状态提示不可见的问题；通知成功提示在详情内可见，空提示不占空间。

## 浏览器操作验证

- 作者回复文字草稿：返回列表、刷新、重新进入后保留。
- 作者修改已发回复；用户修改已发公开消息后显示“已编辑 · 待审核”。
- 作者选择 PNG 并发送附图回复，消息出现“查看附图”入口。
- EPhone 报错模板的功能、步骤、预期、实际字段进入提交正文。
- 独立待办创建、保存并重新读取任务摘要。
- 解答按 UWU 来源发布后，在 UWU 信箱出现。
- 凭证导入经服务器核验、确认后显示恢复 1 封信件。
- Edge 实际下载凭证 JSON，核对格式、来源、数量及假凭证后清理测试文件。内置浏览器的下载事件未返回回执，因此改用 Edge 验证实际文件。
- 关联待办统一通知先显示人数与正文预览；确认后分别发入对应对话，320px 详情显示“已通知 1 段对话”。
